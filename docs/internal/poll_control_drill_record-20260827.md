## ドリルが検出した実装バグ（修正済み・コミット済み）

1. **kintone DATETIME の分切り捨てで BATCH 照合が常に空振り**（ドリル 3 で検出）— `started_at` は分単位に切り捨てられるため、秒付きの claim 時刻との `>` 比較を同じ分に始まった resume が満たせない。基準時刻を分頭へ floor し `>=` 比較へ変更。修正後ドリル 2 で `rerun_batch_id` 確定を確認
2. （レビュー時に事前修正済み）`toISOString()` のミリ秒混入・`evidenceMatches` の厳密文字列比較

## 実機で確認された運用上の事実

* API トークン（`KSQL_TOKEN_LOGS`）には**レコード削除権が無い**（403 GAIA_NO01）— ポーラーの権限は必要最小で正しいことの裏返し。合成レコードの削除は人間の UI 操作
* `pkill -f` にドリルのパターン文字列を渡すと **SSH セッション自身を殺す**（コマンドライン全体がマッチするため）。ドリル手順書に注意として残す
* seed 系ドリルはルックアップ先（顧客 `KSQL-FLOW-TEST-C1`）の存在が前提 — `seed_customer.sql` を追加した
